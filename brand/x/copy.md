# Post copy

Everything here is written to be posted as-is. The images it goes with are in
this folder; the rules below are what stop the copy drifting away from what the
site actually does, which is the only thing this product is selling.

## The rules, before the copy

These are not style preferences. Each one is a claim the site refuses to make
about itself, and copy is where that discipline gets lost first.

**Never "any premise."** Refusing is the product. A post promising a book for
whatever you type contradicts the one feature worth talking about, and the
first person to test it will find out inside a minute.

**Never call it AI.** A language model reading the premise is on the *not
built* list on `/status`. The matcher is a published keyword index with
negative terms. Saying otherwise is the easiest lie to tell in this category
and the easiest to catch.

**No performance figures yet.** Market prices are real now, but the tracking
history has not been checked against a second source, which is why `/track` is
still out of the sitemap. A return in a post travels without the caveat that
follows it everywhere on the site. Post the method, not the numbers.

**The contract address appears on igitur.xyz and here at the same moment, and
nowhere else first.** `/token` and `/legal` both promise this. It is only worth
something if it is never broken, including by a post that is a few minutes
early.

**No emoji, no exclamation marks, no "🚀".** Not squeamishness — the whole
positioning is that this tool says less than it could rather than more. Copy
that shouts undoes the thing the product is quietly claiming.

**Say what it will not do.** The strongest line the site has is a list of
refusals. Use it.

**Everything here fits in 280 characters**, so it posts from a free account
with no thread-splitting and no truncation. The token post was 311 and was cut
down rather than allowed to run long: if one of these ever has to be trimmed
again, cut the description, never the warning or the disclaimer.

## Replies

more than answering them well once.

> No. It is research output. Nothing here places an order, holds money, or tells

**"How is this different from a screener?"**

> A screener starts from filters. This starts from a claim you can state, and
> returns the reason each name earned its weight — with the argument that would
> break the thesis printed next to the one for it.

**"Does it use AI?"**

> Not today. The matcher is a published keyword index with negative terms to
> stop cross-sector mismatches, and the weighting formula is application code so
> the weights stay auditable. A model reading the premise is on the not-built
> list at igitur.xyz/status.

## What to post after launch

The record is the only thing here that gets more interesting with time. A book
posted today is an opinion; the same book quoted in six months against the index
is evidence, and it is the one kind of post nobody can make on day one.

Wait for the claims to age. Then post the ones that lost, too — the site does
not hide them, and a launch account that only quotes its winners has quietly
become the thing this whole product is arguing against.
